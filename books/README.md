# مصدر الكتب وترخيصها

في Markdown. تشمل النسخ فقرات نص المصدر وأبوابه، وليست ملخصات أو نصوصًا مولّدة.

نسبة النصوص: المؤلفون المذكورون ومساهمو ويكي مصدر. جميع روابط النسخ الدائمة
ومصادر أبواب كليلة ودمنة محفوظة في `catalog.json`؛ يمكن تتبع المساهمين من
سجل تاريخ كل صفحة مصدر.

نصوص النسخ هنا وفق ترخيص
[المشاع الإبداعي: النسبة — المشاركة بالمثل 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
ينبغي إبقاء هذه النسبة وروابط المصادر والترخيص عند إعادة التوزيع، وترخيص
التعديلات على النصوص وفق شروط المشاركة بالمثل.

**التغييرات:** أُزيلت أدوات التنقل وبيانات الموقع، وأُعيد تمثيل العناوين
والقوائم في Markdown. قُسمت الفقرات الطويلة عند نهايات الجمل لتحسين القراءة
دون إعادة صياغة كلماتها. أُضيفت عناوين «المقطع» المرقمة للنص الذي لا يتضمن
عناوين فرعية، بغرض التنقل فقط. أغلفة الكتب ورسوم الواجهة تصميم أصلي لرِواق،
وليست أغلفة الطبعات الأصلية.

هذه نسخ قراءة تجريبية، لا طبعات محققة. قد تحتوي نصوص المصدر على أخطاء نسخ
أو تكرار، وينبغي مراجعتها عند الاعتماد عليها في البحث أو النشر.
